# Big-Nuggets-Modded-Server
Home of the Big Nuggets' modded Minecraft server!


# How to install the Fabric Mod Loader:

To join Big Nuggets Modded, you will need the collection of mods provided in the above section.
On top of this, you will need to download and install the Fabric Mod Loaded for Minecraft Java.
This can be found at https://fabricmc.net/use/installer/
Click the download version that matches your OS and run the file. Click the version dropdown on "Client" and select the version matching the server.
### The Server is currently running version 26.2
Once it says it has completed the install, you can close the window!


# How to join the server:

To join the server, you will need the mod pack zip file from this repository.
Download and unzip the folders.
Once you have unzipped them, navigate to your "mods" folder in your .minecraft Appdata file.
  - For Windows, you can access this easily by hitting the Windows Key and typing "%appdata%"
  - This will take you directly to your AppData folder, and .minecraft is usually at the top.
In the previous window, copy the mods from the unzipped folders and paste them into .minecraft\mods
Now you can launch the Fabric option in your Minecraft client and join the server!
### As this is a semi-private server, if you have come across this page, you will likely already have the IP.
 - It will not be provided here. :) Have fun!


# Mods
The Mods are separated into different packs due to Github size limitations (curse you 25mb) lol...
The required mods are labeled as Core
- You also need the Biomes O Plenty mod; it is core but quite large on its own, so it has its own zip file (sorry)
- The Better Client Mods are performance and client enhancing mods, including the mod list, sodium, iris, etc.
- The Optional Mods are visual tweaks, minimap, Voice Chat, etc.
  ### Proximity Voice chat is supported and encouraged for the server!
